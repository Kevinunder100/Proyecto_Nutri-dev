# Proyecto NutriChef 🥗

> **Nota:** Este es el repositorio principal. El desarrollo activo se encuentra en la rama [`dev`](https://github.com/Kevinunder100/Proyecto_Nutri-dev/tree/dev).

## 📖 Descripción
NutriChef es una aplicación web diseñada para ayudar a los usuarios a encontrar recetas saludables basadas en los ingredientes que tienen en casa. El objetivo es facilitar la planificación de comidas nutritivas, reducir el desperdicio de alimentos y promover hábitos saludables.

## 🚀 Tecnologías
El proyecto está construido utilizando un stack moderno y ligero:

*   **Backend**: Node.js con Express y TypeScript.
*   **Base de Datos**: SQLite con Prisma ORM.
*   **Frontend**: HTML5, CSS3 (Vanilla) y JavaScript.
*   **Seguridad**: Autenticación con JWT y Bcrypt.

## 🛠️ Características Principales
*   **Búsqueda Inteligente**: Encuentra recetas por nombre, categoría o ingredientes disponibles.
*   **Filtros Avanzados**: Filtra por tipo de comida (Desayuno, Comida, Cena, Postre).
*   **Gestión de Usuarios**: Registro e inicio de sesión seguro.
*   **Diseño Responsivo**: Interfaz moderna y adaptable a dispositivos móviles.

## 📦 Instalación (Desarrollo)
Para contribuir o probar la versión de desarrollo, cambia a la rama `dev`:

```bash
git checkout dev
npm install
npm run dev
```
